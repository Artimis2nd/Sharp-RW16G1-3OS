# การจัดพาร์ทิชัน (Partitioning)

เอกสารนี้อธิบายแนวคิดและขั้นตอนการแบ่งพาร์ทิชัน
สำหรับโปรเจกต์ Sharp RW-16G1 แบบ Multi-OS (Windows + Bliss OS + Batocera)

⚠️ **คำเตือน**
- การจัดพาร์ทิชันมีความเสี่ยงต่อข้อมูล
- ควรสำรองข้อมูลทั้งหมดก่อนเริ่ม
- ทำตามลำดับที่แนะนำเท่านั้น

---

## 🧠 แนวคิดการแบ่งพาร์ทิชัน

แนวคิดหลักของโปรเจกต์นี้คือ  
**แยกพื้นที่ให้แต่ละ OS ทำหน้าที่ของตัวเองอย่างชัดเจน**

- Windows → ระบบหลัก + โปรแกรม + เกม PC
- Data → เก็บไฟล์ / ROM / งานส่วนตัว
- Bliss OS → เกม Android และแอปจอสัมผัส
- Batocera → ระบบ Retro แบบเต็มรูปแบบ

ไม่แนะนำให้ใช้พาร์ทิชันร่วมกันระหว่าง OS

---

## 🧱 โครงสร้างพาร์ทิชันที่ใช้ (ภาพรวม)

ทุกกรณีจะใช้โครงสร้างพื้นฐานดังนี้:

| Partition | ระบบ | หมายเหตุ |
|---------|-----|---------|
| EFI System | ทุกระบบ | ห้ามลบเด็ดขาด |
| Windows | Windows 10 | NTFS |
| Data | ใช้ร่วม | NTFS |
| Bliss OS | Android | ext4 |
| Batocera | Retro | ext4 (ติดตั้งภายหลัง) |

---

## 💾 กรณีที่ 1: SSD 128 GB (แนวทางอ้างอิง)

เหมาะสำหรับการใช้งานพื้นฐานและทดลองระบบ

| พาร์ทิชัน | ขนาดโดยประมาณ |
|----------|---------------|
| EFI System | เดิมจากเครื่อง |
| Windows 10 | ~50 GB |
| Bliss OS | ~30 GB |
| Batocera | ~40 GB |
| เหลือ / สำรอง | เล็กน้อย |

📌 หมายเหตุ  
- พื้นที่ค่อนข้างจำกัด
- ไม่เหมาะกับเกม PC ขนาดใหญ่

---

## 💾 กรณีที่ 2: SSD 512 GB (ชุดที่ใช้งานจริง)

**การจัดสรรตามที่ใช้งานจริงของเครื่องนี้**

| พาร์ทิชัน | ขนาด | ระบบไฟล์ |
|----------|------|----------|
| EFI System | เดิม | FAT32 |
| Windows 10 | 150 GB | NTFS |
| Data (เก็บข้อมูล) | 150 GB | NTFS |
| Bliss OS (Android) | 100 GB | ext4 |
| Batocera | ~110 GB | ext4 |

📌 โครงสร้างนี้เหมาะกับ:
- เกม PC ขนาดกลาง
- ROM จำนวนมาก
- เกม Android หลายเกม
- Retro ครบหลายระบบ

---

## 🛠️ ขั้นตอนการแบ่งพาร์ทิชัน (ทำบน Windows)

### 1️⃣ เตรียมระบบ
- บูตเข้า Windows
- กด `Win + X` → เลือก **Disk Management**

### 2️⃣ Shrink พาร์ทิชัน Windows
- คลิกขวาที่ไดรฟ์ Windows
- เลือก **Shrink Volume**
- ลดขนาดให้เหลือ **150 GB**

### 3️⃣ สร้างพาร์ทิชัน Data
- คลิกขวาที่พื้นที่ว่าง
- เลือก **New Simple Volume**
- ขนาด **150 GB**
- ฟอร์แมตเป็น **NTFS**
- ตั้งชื่อเช่น `DATA`

### 4️⃣ เตรียมพื้นที่สำหรับ Bliss OS และ Batocera
- พื้นที่ที่เหลือ **อย่าสร้าง Volume**
- ปล่อยให้เป็น **Unallocated**

⚠️ สำคัญมาก  
- ห้ามฟอร์แมตล่วงหน้า
- Bliss OS และ Batocera จะจัดการเองตอนติดตั้ง

---

## ❌ สิ่งที่ห้ามทำเด็ดขาด

- ❌ ห้ามลบ EFI System Partition
- ❌ ห้ามใช้โปรแกรมจัดพาร์ทิชันมั่ว ๆ
- ❌ ห้ามฟอร์แมตพื้นที่ Android / Batocera ล่วงหน้า
- ❌ ห้ามติดตั้ง OS พร้อมกันหลายตัว

---

## 🧪 ปัญหาที่พบบ่อยจากการแบ่งพาร์ทิชันผิด

| ปัญหา | สาเหตุ |
|-----|------|
| บูตไม่ขึ้น | EFI เสีย |
| OS หาย | เลือกพาร์ทิชันผิด |
| Batocera พัง | ฟอร์แมตผิด |
| Bliss OS ไม่บูต | ext4 ไม่สมบูรณ์ |

---

## ✅ สรุป

- การวางแผนพาร์ทิชันสำคัญกว่าการติดตั้ง OS
- SSD 512 GB เหมาะกับการใช้งานจริงที่สุด
- ปล่อยพื้นที่ Unallocated คือหัวใจของระบบนี้

> **คิดให้จบก่อนลงมือ = ระบบเสถียรในระยะยาว**
